# خطة نقل المحرك إلى خادم VPS 66

الهدف: يصبح الخادم `213.156.132.166` هو مقر التخزين والإنشاء والذكاء، وتبقى هذه الواجهة للعرض فقط، ويفتحها تطبيق الهاتف.

## 1) توزيع الأدوار

```text
الهاتف (Capacitor)  ──▶  الواجهة الحالية (عرض فقط)  ──▶  خادم VPS 66
                                                        ├─ محرك النواة (API)
                                                        ├─ قاعدة بيانات PostgreSQL
                                                        ├─ تخزين الملفات والنتائج
                                                        ├─ طابور مهام الإنشاء
                                                        └─ اتصال بخدمات HN فقط
```

- الواجهة لا تنشئ ولا تخزن شيئًا: ترسل الطلب، تتابع حالته، تعرض النتيجة.
- تطبيق الهاتف يفتح `https://chat.hn-chat.com` نفسه (نفس الحساب ونفس النتائج).

## 2) ما يُركَّب على الخادم

| المكوّن | الدور |
|---|---|
| Nginx + شهادة HTTPS | بوابة الدخول على نطاق فرعي `api.hn-chat.com` |
| خدمة المحرك (Node) | نقاط الطلب: محادثة، صورة، صوت، فيديو، موقع، سيرة ذاتية، تحليل صورة |
| PostgreSQL | القوالب، المستخدمون والأدوار، الوظائف، السجلات، الإعدادات، المعرفة |
| مجلد التخزين | ملفات النتائج مع روابط تحميل موقّعة |
| طابور المهام | كل إنشاء يصبح «وظيفة» لها حالة: بانتظار، جارٍ، منتهٍ، فشل |
| خدمة مراقبة | إعادة تشغيل تلقائية وسجلات يومية |

## 3) العقد بين الواجهة والخادم

نقاط ثابتة يتحدث بها الطرفان:

- `POST /v1/ask` — سؤال النواة: يرد فورًا من القوالب إن وُجد تطابق، وإلا يفتح وظيفة.
- `POST /v1/jobs` — طلب إنشاء (صورة/صوت/فيديو/موقع/سيرة/تحليل صورة) يرجع رقم الوظيفة.
- `GET /v1/jobs/:id` — حالة الوظيفة ونتيجتها ورابط ملفها.
- `GET /v1/templates` و`PUT /v1/templates/:code` — قراءة وتعديل القوالب من لوحة التحكم.
- `GET /v1/admin/*` — بيانات لوحة التحكم (نظرة عامة، مستخدمون، خدمات، سجلات).
- كل الطلبات موقّعة بمفتاح الجلسة؛ لا نقطة مفتوحة بلا تحقق.

## 4) نقل البيانات

1. تصدير الجداول الحالية كاملة: `templates` (111 قالبًا بمعرفاتها S00001…)، الأدوار، الإعدادات، الخدمات، السجلات، الوظائف.
2. إنشاء نفس البنية على قاعدة الخادم مع نفس قواعد الحماية (كل مستخدم يرى بياناته، الطاقم يرى الكل).
3. استيراد البيانات والتحقق من تطابق العدد سطرًا بسطر.
4. لا يُحذف شيء من القاعدة الحالية — تبقى نسخة مرجعية.

## 5) تعديل الواجهة هنا

- استبدال نداءات الإنشاء الداخلية بنداءات إلى الخادم عبر عنوان واحد في الإعدادات.
- شاشة الدردشة: إرسال ← عرض «جارٍ العمل» ← عرض النتيجة عند اكتمال الوظيفة.
- لوحة التحكم وصفحة القوالب تقرأان وتكتبان على الخادم مباشرة.
- إبقاء الأزرار والتصميم كما هي دون أي تغيير شكلي.

## 6) الهاتف

- التطبيق يفتح الموقع نفسه، مع حفظ الحساب وعدم طلب البيانات كل مرة.
- عند انقطاع الشبكة: عرض آخر نتائج محفوظة محليًا ورسالة واضحة.
- بناء ملف APK بعد استقرار الخادم.

1. تأكيد النطاق الفرعي للمحرك (`api.hn-chat.com` أو غيره) وتوجيهه إلى `213.156.132.166`.
2. طريقة الدخول إلى الخادم لتثبيت الخدمة.
