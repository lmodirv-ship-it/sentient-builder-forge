# لوحة تحكم النواة + نواة نموذج ذكي لمجموعة HN

## الهدف
1. حساب مالك واحد (lmodirv@gmail.com) بصلاحيات كاملة لا يمكن حذفه أو تخفيض رتبته.
2. لوحة تحكم كاملة لإدارة المنصة: المستخدمين، الصلاحيات، خدمات HN، المفاتيح، السجلات، الاستهلاك، القوالب.
3. نواة نموذج ذكي (Nawat Core) تتعلم من كل عملية وتتحسّن باستمرار، معتمدة حصريًا على خدمات HN.

## 1) الأدوار والمالك
- جدول أدوار منفصل (`app_role`: owner / admin / editor / user) — لا تُخزَّن الرتبة في ملف المستخدم.
- دالة `has_role` آمنة تُستعمل في كل سياسات الحماية.
- حماية المالك: مُشغِّل قاعدة بيانات يمنع حذف صف دور `owner` أو تغييره أو حذف حساب المالك، ويمنع منح `owner` لأي حساب آخر.
- المالك يُثبَّت على البريد أعلاه تلقائيًا عند أول تسجيل دخول بهذا البريد (كلمة السر تُسجَّل من صفحة الدخول، لا تُخزَّن في الكود).

## 2) جداول لوحة التحكم
| الجدول | الغرض |
|---|---|
| `profiles` | بيانات المستخدم الظاهرة (اسم، صورة، آخر دخول، حالة الحظر) |
| `user_roles` | الأدوار (owner/admin/editor/user) |
| `hn_services` | خدمات HN: المعرّف، الاسم، الرابط، القدرات، مفعّل/معطّل، الأولوية |
| `hn_service_health` | نتائج فحص الاتصال الدوري لكل خدمة (زمن الاستجابة، آخر خطأ) |
| `platform_settings` | إعدادات عامة (اسم المنصة، الشعار، الوضع الافتراضي، حدود الاستخدام) |
| `generation_jobs` | كل عملية إنشاء (نوع، طلب، خدمة، حالة، مدة، تكلفة، نتيجة) |
| `activity_logs` | سجل تتبّع موحّد (من، ماذا، متى، معرّف الطلب، سبب الفشل) |
| `templates` | قوالب المواقع/الفيديو/الصور/السير الذاتية مع وسوم واستخدام |
| `usage_quotas` | حدود يومية/شهرية لكل مستخدم أو دور |
| `knowledge_items` | ذاكرة النواة: طلب + خدمة + نتيجة + تقييم + تضمين (embedding) |
| `feedback_events` | إعجاب/عدم إعجاب/إعادة توليد لكل نتيجة — وقود التعلّم |
| `model_policies` | قواعد التوجيه المُتعلَّمة: نية → أفضل خدمة HN + أفضل صيغة طلب |

كل الجداول مع RLS وصلاحيات: المالك والمدير يرون كل شيء، المستخدم يرى صفوفه فقط.

## 3) بنية النواة الذكية (Nawat Core) — مدمجة مع OCR المحسّن، خريطة المعرفة، والتفريغ الصوتي المحلي (Whisper)
خمس طبقات، كلها فوق خدمات HN فقط:

```text
الإدراك   → تحليل الطلب: اللغة، النية، الموضوع، المرفقات
الاسترجاع → بحث دلالي في knowledge_items عن حالات مشابهة ناجحة
التوجيه   → اختيار خدمة HN وصيغة الطلب من model_policies (مع بديل احتياطي)
التنفيذ   → استدعاء الخدمة، تتبّع كامل، إعادة محاولة ذكية
التعلّم   → تسجيل النتيجة + التقييم، تحديث أوزان القواعد وترقية أفضل الصيغ
```

حلقة التعلّم: كل عملية تُكتب في `generation_jobs` + `knowledge_items`؛ وظيفة دورية تحسب معدّل النجاح ورضا المستخدم لكل (نية × خدمة × صيغة) وتحدّث `model_policies`. النتيجة: كلما زاد الاستعمال، صار الاختيار أدق والاستجابة أسرع (إعادة استخدام النتائج المخزّنة).

## 4) واجهة لوحة التحكم `/admin`
محمية بـ `has_role(owner|admin)`، أقسام:
- **نظرة عامة**: عدد العمليات، نسبة النجاح، أسرع/أبطأ خدمة، مستخدمون نشطون.
- **المستخدمون**: بحث، تغيير الدور، حظر/فك، تصفير الحدود (المالك محميّ ومعطّل الأزرار).
- **خدمات HN**: تفعيل/تعطيل، ترتيب الأولوية، فحص اتصال فوري، تعديل الرابط.
- **المفاتيح والإعدادات**: إدارة الإعدادات العامة وحالة المفاتيح (بدون كشف قيمها).
- **السجلات**: تتبّع الطلبات مع سبب الفشل والتصفية.
- **القوالب**: إضافة/تعديل/أرشفة، إحصاء الاستخدام.
- **النواة**: عرض القواعد المُتعلَّمة، إعادة تدريب يدوي، مسح الذاكرة السيئة.

## 5) خطة التطوير البرمجية (مراحل) — مع خطوات تجربة: OCR على صورة عربية خافتة، الضغط على وسم في خريطة المعرفة، والتفريغ الصوتي عبر Whisper المحلي
1. **الأساس**: الأدوار + حماية المالك + `profiles` + بوابة `/admin`.
2. **الإدارة**: جداول الخدمات والإعدادات والسجلات + شاشات المستخدمين والخدمات.
3. **التتبّع**: ربط كل دوال الإنشاء الحالية بـ `generation_jobs` و`activity_logs`.
4. **الذاكرة**: `knowledge_items` + `feedback_events` + أزرار التقييم في الاستوديو.
5. **التعلّم**: البحث الدلالي + `model_policies` + وظيفة التحديث الدورية.
6. **التحسين**: الحدود والحصص، لوحة الإحصاءات، إعادة استخدام النتائج للسرعة.

## تفاصيل تقنية
- الأدوار عبر enum + جدول منفصل + دالة `security definer`؛ لا رتب في `profiles`.
- كل جدول عام: `CREATE TABLE` ثم `GRANT` ثم `ENABLE RLS` ثم السياسات.
- الواجهة: مسارات تحت `_authenticated/admin` مع حارس دور، وقراءة عبر `createServerFn` بوسيط `requireSupabaseAuth`.
- البحث الدلالي بالتضمينات عبر خدمة HN المخصّصة؛ لا مزوّد خارج HN.
- حماية المالك بمُشغِّلات قاعدة بيانات، لا بفحص واجهة فقط.
