# دراسة شبكة HN (150+ موقع) وربطها بالنواة

## الواقع التقني
دراسة 150 موقعاً واحداً واحداً غير عملي في جلسة واحدة (سيستهلك أضعاف رصيدك من Firecrawl + AI). الحل الذكي: **دمج + تجميع + استخراج تلقائي**.

## المرحلة 1 — التنظيف والتوحيد (فوري، بدون تكلفة)
- إزالة تكرارات `www.` (تخفض القائمة من 150 إلى ~95 موقعاً فريداً).
- إزالة النطاقات المتشابهة (`goupe-hn.com/.fun/.online/.site` = نفس المشروع غالباً).
- تجميع النطاقات الفرعية تحت المشروع الأم:
  - `hn-driver.com` + `admin.` + `client.` + `driver.` + `super.` + `callcentre.` + `ride.` + `stouk.` = **مشروع HN Driver** (8 واجهات).
  - `hn-db.fun` + `admin.` + `api.` + `ai.` + `auth.` + `files.` + `owner.` + `rule.` + `status.` + `users.` + `ws.` = **مشروع HN DB** (11 واجهة).
  - وهكذا لبقية العائلات.
- الناتج: **~20 مشروعاً أُماً** بدل 150 نطاقاً.

## المرحلة 2 — البنية داخل النواة (بدون إنترنت)
- إنشاء `src/lib/hn-ecosystem.ts`: شجرة كاملة (مشروع → واجهات → فئة → دور محتمل).
- تبويب جديد **"🌐 شبكة HN"** يعرض:
  - الفئات (مغسلة/طباعة، نقل، AI، إعلام، مالية، عقار، إلخ).
  - كل مشروع كـ card قابل للتوسيع مع كل واجهاته.
  - بحث سريع + فلترة.
- زر "افتح" لكل رابط.
- الفئات المستخدمة (من تصنيفك): مغسلة/طباعة، نقل/توصيل، AI، قواعد بيانات، إعلام/فيديو/سينما، مالية/فوترة، عقار، توظيف/CV، أذكار، طبي، عام.

## المرحلة 3 — الاستكشاف التلقائي (Firecrawl، دفعات مضبوطة)
- ربط Firecrawl connector (مرة واحدة).
- زر **"استكشف كل المشاريع"** يعمل بالخلفية:
  - يزور الصفحة الرئيسية لكل مشروع أُم فقط (~20 طلباً، ليس 150).
  - يستخرج: العنوان، الوصف، اللغة، أنواع الأزرار الرئيسية → يستنبط "المهام/القدرات".
  - يحفظ الجدول في `Core memory` للنواة تلقائياً.
- زر منفصل **"استكشف عميق: مشروع X"** لأي مشروع تريد تفاصيل أعمق فيه (يزور الصفحات الداخلية).

## المرحلة 4 — الجدول النهائي والربط
جدول تفاعلي بالأعمدة:
| المشروع | الفئة | عدد الواجهات | المهام (مستخرجة) | نقاط ربط مع النواة |

**نقاط الربط المقترحة تلقائياً حسب النوع:**
- مواقع محتوى (أذكار، بلوق، سينما) → استيراد إلى ذاكرة النواة.
- مواقع خدمات (سائقين، مغسلة) → روابط سريعة + بحث موحد.
- مواقع AI (hn-ai, hn-chat, nawat) → توحيد المحادثات لاحقاً.
- مواقع قواعد بيانات (hn-db, hn-dbpro) → مصادر معرفة للنواة.

## المرحلة 5 (لاحقاً، اختيارياً)
- بحث موحّد يستعلم عدة مشاريع دفعة واحدة.
- إشعارات تحديثات (RSS إن توفر).
- تكامل مباشر لمشاريع مختارة عبر API إن كانت تعرض واحدة.
