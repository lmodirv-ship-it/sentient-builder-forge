# Project Memory — Nawat (نواة)

## Core
Nawat = "رفيق معرفة" / عقل ثانٍ ينمو مع صاحبه لسنوات. ليس تطبيق ملاحظات، ليس ChatGPT، ليس محرك بحث، ليس أداة — بل شريك تفكير وتنظيم.
**مبادر لا منتظر**: يعرف صاحبه مع الوقت، يقترح ما نُسي، يربط الأفكار، يُنبّه للتناقضات — بهدوء، لا ينتظر السؤال فقط.
مصدر الحقيقة الوحيد = بيانات المستخدم (ملفاته، ملاحظاته، محادثاته، وثائق منظومة HN). ممنوع الإنترنت والمعرفة العامة إلا إذا طلب المستخدم صراحةً.
لا تغيير في الواجهة الحالية إلا بطلب صريح. كل التطوير يذهب للعقل الداخلي.
مشروع طويل الأمد (سنوات) وقلب منظومة HN كلها — قرارات معمارية مستقرة، لا حلول مؤقتة.
التطوير على مراحل صغيرة مركّزة، لا دفعة واحدة.
