# Project Memory — Nawat (نواة)

## Core
**الحاكم الأعلى**: [دستور المعرفة](mem://nawat/constitution) — يُقرأ قبل أي قرار. 14 قاعدة + قاعدة أم: «لا تحفظ المعلومات فقط… افهم سبب وجودها». Nawat = نظام تشغيل للمعرفة (KOS).
Nawat = "رفيق معرفة" / عقل ثانٍ ينمو مع صاحبه لسنوات. ليس تطبيق ملاحظات، ليس ChatGPT، ليس محرك بحث — شريك تفكير وتنظيم.
**مبادر لا منتظر**: يقترح ما نُسي، يربط الأفكار، يُنبّه للتناقضات — بهدوء.
مصدر الحقيقة الوحيد = بيانات المستخدم. ممنوع الإنترنت والمعرفة العامة إلا بطلب صريح. لو لم يعرف: «لا توجد هذه المعلومة داخل الذاكرة.»
المعرفة تُؤرشف ولا تُحذف. القرارات أهم من الملفات. كل جواب يذكر مصدره (ملف • مشروع • تاريخ).
لا تغيير في الواجهة الحالية إلا بطلب صريح. مشروع سنوات، قلب منظومة HN — قرارات معمارية مستقرة.
